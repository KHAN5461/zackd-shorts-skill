## ⚡ The 3-Stage Workflow at a Glance

| Stage | Name | Output & Strict Constraints |
| :--- | :--- | :--- |
| **Stage 0** | **Ideation & Scoring** | High-tension titles in 4 categories with virality ratings (0–10). |
| **Stage 1** | **Script Creation** | Exactly 10 scenes, exactly 8–12 words per sentence, continuous unbroken narrative. |
| **Stage 2** | **AAA Cutscene Image Prompts** | Unreal Engine 5.4 style, persistent character anchor string, 3–5 lines per prompt. |
| **Stage 3** | **Video Animation Mastery** | Timestamped blocks (`0-2s`, `2-4s`, `4-6s`), real physics, physical facial expressions, locked final frames. |

## 🚀 How to Install & Use

### 1. In Claude.ai (Projects & Custom Instructions)
1. Open your Claude Project or User Settings in Claude.ai.
2. Open [`claude_project_prompt.md`](file:///c:/Users/Admin/Documents/antigravity/excited-bell/skills/zackd-viral-shorts/claude_project_prompt.md).
3. Copy and paste the entire prompt into the **Project Instructions** or **Custom Instructions**.
4. Start chatting by prompting: *"Generate 5 viral video ideas for survival scenarios"* or *"Create a script for: What happens if you get struck by lightning?"*.

### 2. In Antigravity / Claude Code
The skill is pre-configured in `.agents/skills/zackd-viral-shorts/SKILL.md`. Antigravity automatically detects and progressively activates the skill whenever you request Zack D Films style shorts or video prompting.

### 3. In AI Video & Image Generators
- **Images:** Midjourney v6, Flux.1 Pro, DALL-E 3, Stable Diffusion XL.
- **Videos:** Google Veo 3, Kuaishou Kling 1.5/2.0, OpenAI Sora, Wan 2.1, Minimax Hailuo AI.
